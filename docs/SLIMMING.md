# MDSync 占比与精简

比较基线是精简前已上传的提交 `ffe7912`，上游基线为 MDSync v1.5.1 `6f0190e`。以下统计针对当前受版本控制的文件，不包含 Git 历史、node_modules、构建包和本地运行记录。

## 精简前

| 类别 | 文件数 | 文件字节 |
| --- | ---: | ---: |
| 与上游同路径、同内容 | 1,154 | 11,754,411 |
| 修改了上游同路径文件 | 15 | 265,416 |
| 新增路径 | 57 | 234,389 |
| 合计 | 1,226 | 12,254,216 |

原样上游文件占 **94.1%**，对应字节占 **95.9%**。新增路径不等于全部原创：其中包含移植到新路径的合并算法。这个统计反映仓库维护范围，不等于插件运行包的代码来源比例。

精简前的普通模式还通过通用 UI/utils 出口间接引入少量协议和加密模块。0.3.0 改为直接依赖所用纯算法和 Obsidian 宿主 API。

## 精简后

受版本控制的文件从 **1,226 个缩减到 57 个**（减少约 95.4%），总内容从 **12.25 MB 缩减到约 0.22 MB**（减少约 98.2%，含源码、测试、文档和锁文件）。这些数字不包含保留的 Git 历史。

当前为单一插件：`src/`、`tests/`、`tools/`，独立 package.json、TypeScript 配置和构建脚本。不再需要四包 monorepo、@mdsync/protocol、Relay、Viewer、加密模式或上游统一 UI。移除了上游 CLAUDE.md、.claude 规则/技能、发布部署模板和与保留功能无关的说明，仅留项目自己的简短 AGENTS.md 与 CI 模板。

保留 **4 个纯文本算法文件，约 464 行、13,563 字节**，占当前 TypeScript 源码文件体积约 **19.1%**（含来源注释和本地 import 调整）。另有两个极小的预算/出口文件和 18 项对应回归测试。它们是仓库内可独立维护的代码，不依赖 MDSync 包、应用或服务。来源与许可证见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

运行时打包的第三方库只有 `yaml` 和 `@jest/diff-sequences`，Obsidian API 由宿主提供。构建后的插件 JavaScript 从 165,137 降为 159,518 字节，约减少 3.4%；原构建本来已裁掉大部分闲置代码，因此主要收益是缩小源码、维护和构建依赖范围，而非同幅度缩小安装包。

同步行为保持不变：updated 本机保留、只读预览、条件写入、冲突处理和恢复继续测试。旧完整代码保留在 Git 历史以及本地 `archive/mdsync-monorepo-0.2.0` 分支，可以回退；没有重写 GitHub 历史。
