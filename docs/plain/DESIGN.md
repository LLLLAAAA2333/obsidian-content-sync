# 普通目录首版设计

基线：MDSync v1.5.1 / 6f0190e。研究检出保持不动。开发位置 `plain-sync/`。

依赖图：原模式 scan → diff → encrypted content → manifest guard → baseline/journal；新模式 plain/scan → plan(B,L,R) → per-file conditional mutation → durable intent/checkpoint。两个入口分别构建，新包不启动原模式。

复用：上游 core/ui 的窗口和通知、hunks/merge-model 的文本三方合并、现有测试设施和隔离 Obsidian 驱动方式。原本地恢复机制用于设计参考，但其 prefix 恢复和 mtime guard 不满足此次约束，因此新 journal 使用持久化完整版本、不可变检查点和本地移走后核验。保留原实现与许可证。

不变量：完整读取与原始字节 SHA-256 保留；Markdown 顶层 updated 仅在本机，另以去除该属性的共享 SHA-256 比较；扫描永不信任 mtime 缓存；错误不是缺失；首轮不同内容冲突；所有路径来自真实目录；不写共享清单；每路径独立提交；只有完整保存的版本可作为基线；写前保存意图、两侧版本；基线只在确认两侧共享内容一致后推进；未知能力禁用远端写入；无历史 GC。

范围：桌面专用，Node 流式 I/O（64 KiB 缓冲，扫描并发 2），所有扩展名，默认排除配置/元数据/垃圾目录和符号链接；大小写和 Unicode 规范化碰撞保守阻止。空目录不传播，不自动重命名（按新增/删除处理）。文本合并只对小于 1 MiB 的普通 Markdown，经用户选择，重叠修改留作冲突。

本地文件系统没有与任意外部编辑器协作的原子 compare-and-swap。覆盖/删除将旧 inode 移至唯一恢复路径，再核验并以 exclusive hard-link 发布新文件；新出现的文件不会被覆盖。被移走 inode 的迟到编辑仍在恢复目录，发生不匹配时停止。此限制必须在说明中保留，不能宣称对任意编辑器拥有事务保证。状态保存 fsync + rename，检查点不覆盖历史；损坏最新检查点停止。操作锁防止同库多引擎执行。

WebDAV 必须具备原子 If-None-Match:* 新建、强 ETag 条件 PUT/DELETE 和完整发布语义。探测含重叠/延迟请求体，结果仅是观测证据。首版仅自动授权本地模拟服务；真实服务即便探测通过仍须明确服务端保证，默认只读。用户后续明确授权使用现有 Simple WebDAV Sync 设置完成了科大只读 dry run；映射来自该设置，凭据仅在内存使用，未验证或授权真实写入。

目录列举不是快照：任何列举或文件读取失败都使本轮不执行；执行逐路径重新 GET 两侧及缺失项；条件写以当时强 ETag 为前提。服务器静默漏列且 GET 同样错误属于服务器能力边界。中断后恢复先观察实际结果；不符合旧值或目标值则保留意图为冲突，不重新覆盖。多文件部分成功保留已提交基线。

## 0.2.0 本机 updated

`content.ts` 以 YAML AST 的源范围移除顶层 updated，不重新序列化其他字段；缓冲文件头最多 256 KiB，正文仍流式读取。`Seen.hash` 是原始字节哈希，`Seen.syncHash` 是共享表示哈希。存储层 read 同时计算两者；真实修改前仍检查原始哈希及 ETag。读出格式不安全时视为未知，不回退成上传完整 updated。

基线、三方比较和合并使用共享表示；两侧原始内容及共享表示都按内容寻址归档。下载前 `local-version.ts` 把本机原有 updated 插入共享目标，原字段不存在则保持不存在。持久化意图分别记录共享目标 `desired` 和本机完整目标 `localDesired`，崩溃恢复验证两份文件。更新时间变化不导致同步写入，其他字段和正文仍参与冲突判定。

检查点升为 format 2，format 1 不作静默转换；显式迁移尚未实现。对尚未建立普通模式基线的真实库，预览仍不创建任何状态。远端已经存在的 updated 不因接管而强制改写，真正上传内容时才去掉。
