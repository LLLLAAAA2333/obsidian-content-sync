# 桌面操作界面

Mode: Operate。已有 Obsidian / MDSync 原生视觉系统内的窄功能扩展，code-led，无新品牌、无图片参考稿、无移动端交付。

THESIS: 核验实际内容之后，由用户审阅并触发同步。
OWN-WORLD: Obsidian 原生主题、系统字号、主题强调色、MDSync modal-frame、原生 Setting/Button。主题颜色为视觉依据，不新增调色板。
STORY: 设置明确目标 → 完整核验 → 分类计划 → 只读比较冲突正文 → 明确确认执行 / 选择 → 更新计划；异常保留恢复入口。
FIRST VIEWPORT: 标题和目标、只读/模拟模式说明、核验/恢复/执行按钮、读取量与改写数、待处理列表、排除规则。
FORM: 简洁文本行、原生控件、路径可换行，状态同时使用文字和颜色；长列表限制渲染 200 项。沿用模态窗口的键盘操作和弹出行为。

证据：artifacts/obsidian-preview.png（900 CSS px 宽桌面窗口），obsidian-narrow.png（560 CSS px），obsidian-comparison.png，obsidian-recovered.png。截图均为隔离合成数据；Obsidian 1.14.4 的原生设置窗口承载模态，测试需跟随 about:blank CDP 页面。

技能 context 脚本无执行权限，已直接检查上游组件与渲染。未运行外部设计 detector；沿用原生组件和源码检查。检查范围限桌面，不声称 iOS/Android 通过。
